================================================
個人作品集網站：架構與維護手冊 (MkDocs + GitHub)
================================================

1. 核心觀念：文件即代碼 (Docs as Code)
--------------------------------------
你的網站不是在網頁介面點出來的，而是透過「撰寫 Markdown 檔案」->「推送到 GitHub」->「機器人自動發布」而成的。這意味著你的所有內容都在雲端有備份，換電腦也不怕。

2. 檔案目錄結構 (重要！)
---------------------------
my-website/
├── .github/workflows/
│   └── publish.yml       <-- 自動化發布機器人 (GitHub Actions)
├── docs/                 <-- 存放所有網頁內容的資料夾
│   ├── index.md          <-- 網站首頁
│   ├── project1.md       <-- 你的專案頁面 (可自行增加)
│   └── about.md          <-- 關於我/聯絡資訊
├── mkdocs.yml            <-- 網站的大腦 (設定主題、顏色、導覽列)
└── .gitignore            <-- 告訴 Git 哪些檔案不要上傳 (通常包含 site/)

3. 日常更新流程 (三步驟)
---------------------------
當你在新設備或目前電腦想要更新內容時：
Step 1: 在 docs/ 裡面新增或修改 .md 檔案。
Step 2: 在 VS Code 終端機輸入：
        git add .
        git commit -m "描述你的更新內容"
Step 3: 推送到雲端：
        git push origin main
剩下的事，GitHub Actions 會自動幫你完成。

4. 換電腦/出國後的銜接步驟
---------------------------
如果你換了一台新筆電，請執行以下步驟找回你的網站：
1. 安裝 Git 與 Python。
2. 下載網站原始碼：
   git clone https://github.com/ccc888ccc/ChangHC.github.io.git
3. 安裝 MkDocs 工具：
   pip install mkdocs-material
4. 進入資料夾並啟動預覽：
   cd ChangHC.github.io
   mkdocs serve

5. 如何讓網站更專業 (針對 OR/金融背景)
---------------------------
- 數學公式：在 .md 檔案中使用 $$ 包含 LaTeX 語法。
- 程式碼：使用 ```python ... ``` 區塊展示你的演算法。
- 導覽列：修改 mkdocs.yml 中的 'nav' 區塊來增加分頁。
- 網址：https://ccc888ccc.github.io/ChangHC.github.io/

6. 疑難排解
---------------------------
- 變更沒反應：確認是否有執行 git push，並檢查 GitHub Actions 頁面是否為「綠色勾勾」。
- 格式亂掉：檢查 mkdocs.yml 的縮排（YAML 語法對縮排非常嚴格）。
